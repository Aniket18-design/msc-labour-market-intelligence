# MSc Labour Market Intelligence Project

## Project Title

**Integrated Labour Market Intelligence for the UK Digital Labour Market: An Analysis of Employer Demand, Salaries, Skills and Regional Trends (2023–2025)**

## Overview

This repository contains the code, processed analytical datasets and outputs developed for an MSc project investigating selected areas of the UK digital labour market between 2023 and 2025.

The project integrates evidence relating to employer demand, occupational salaries, regional labour-market conditions, occupational skills and technology indicators.

## Analytical Workflow

Python and Jupyter Notebook were used for:

- Data inspection and validation
- Data cleaning and transformation
- Dataset integration
- Employer-demand analysis
- Salary analysis
- Regional analysis
- Occupational skills and technology analysis
- Pearson and Spearman correlation analysis
- OLS regression
- K-means clustering
- Preparation of analytical datasets for Power BI

Power BI was used to develop the interactive Labour Market Intelligence dashboard.

## Repository Structure

### `Notebook/`

Contains the Jupyter notebooks used throughout the analytical workflow, including data inspection, demand and salary analysis, dataset integration, statistical analysis, regression, clustering, O*NET analysis and Power BI preparation.

### `data/processed/`

Contains processed analytical datasets generated and used during the project.

### `results/`

Contains selected analytical visualisations generated from the Python analysis.

## Scope

The core occupational analysis covers:

- Software Development
- Cybersecurity
- Data Analytics

The regional analysis covers:

- London
- North West
- West Midlands

AI is included within the technology analysis where supported by the available evidence. Software Development is not used as a substitute for AI in the occupational demand-and-salary analysis.

## Methodological Note

The statistical and machine-learning analyses are exploratory. The final occupation-year dataset contains nine observations representing three occupational categories across 2023, 2024 and 2025.

Online job-advertisement demand is interpreted as recruitment activity rather than total employment.

O*NET skills and technology indicators are used as complementary occupational evidence and are not interpreted as direct measures of UK vacancy demand.

## Data Availability

Raw/source datasets are not included in this repository. The repository contains processed analytical data required to demonstrate the analytical workflow where appropriate.
